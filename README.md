# Devine Le Nombre

Auteurs :
- Abass Fofana
- Denise Fofana

Description :
Le joueur doit trouver un nombre secret entre 1 et 100.

Comment lancer le jeu :

python main.py

Règles :
Le programme choisit un nombre secret.
Le joueur entre un nombre.
Le programme indique si le nombre est trop grand ou trop petit.
La partie continue jusqu'à ce que le joueur trouve le nombre secret.

Fichiers du projet :
- main.py
- jeu.py
- joueur.py
- sauvegarde.py
